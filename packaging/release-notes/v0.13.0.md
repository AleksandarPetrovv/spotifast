## Features

* everything from upstream spotifast 0.13.0: google cast speakers, upcoming albums with pre-save, removing one song from the queue, a by you filter for playlists, a faster start, lower battery use, and many fixes (sonos, resuming paused playlists, rate limits and more)
* updates are signed: the app only installs a release whose checksums carry this fork's signature
* windows now also gets a windows installer package (`.msi`)
* still here: song, album and playlist downloads, youtube / soundcloud / local songs in playlists, romanization, the extra lyrics providers and the emoji font picker

## Downloads

* windows: `spotifast-v0.13.0-x86_64-pc-windows-msvc.msi`. the `-setup.exe` is still here so 0.12.0 can update itself; the next release only ships the `.msi`
* mac: `spotifast-v0.13.0-macos-universal.pkg`
